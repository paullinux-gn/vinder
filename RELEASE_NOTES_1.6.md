# Vinder 1.6

- Three-way segmented view selector for icon view, list view, and expandable list view, with a separate view-options button.
- Remember each folder's view mode independently.
- Segmented folder path with a raised current-folder button and vertical dividers.
- Private sidebar shortcuts, imported once from existing GTK bookmarks and then kept independent of Nautilus.
- Centered, bold PLACES, SHORTCUTS, and NETWORK sidebar captions.
- Rounded file-content area, refined sidebar panels, and improved light-theme zebra stripes.
- Correct selected-icon contrast in the Dark + Light theme.
- Open the default terminal in the context menu's folder.
- Preserve system-font integration in Flatpak builds.

Includes the existing startup optimisations and idle thumbnail preparation for the Pictures folder.
